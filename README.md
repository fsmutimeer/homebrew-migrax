# Homebrew tap for Migrax

[Migrax](https://migrax.org/) generates database migrations from your JPA entities.

```bash
brew install fsmutimeer/migrax/migrax
migrax version
```

Homebrew installs Java with it. When `JAVA_HOME` is set, Migrax uses that Java instead.

Update with `brew upgrade migrax`. This tap is updated automatically by every Migrax release;
see the [installation guide](https://migrax.org/getting-started/installation/).
